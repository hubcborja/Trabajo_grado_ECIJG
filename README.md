# Modelado de la Dinámica Estructural del Comercio Internacional para la Anticipación de Convenios de Doble Tributación (CDT) 

Este repositorio contiene el desarrollo técnico del Trabajo de Grado para optar al título de Magíster en Ciencia de Datos en la Escuela Colombiana de Ingeniería Julio Garavito.  

La investigación se centra en el análisis de la red de comercio internacional de la canasta de productos más representativa para Colombia entre los años 2004 y 2024. A diferencia de los enfoques econométricos tradicionales, este proyecto emplea la Ciencia de Redes y modelos de grafos aleatorios exponenciales (ERGM y variantes) para comprender el proceso generativo de la red comercial.
